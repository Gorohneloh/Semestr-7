# Лабораторная работа №4. Синхронизация потоков и критические секции на C++

Решение Задачи №6 в рамках дисциплины «Аппаратные средства телекоммуникационных систем».

В данной работе реализована параллельная программа с использованием функциональной декомпозиции на базе стандартных потоков C++ (`std::thread`). Вычисление итогового значения по формуле `(Σx + Σy + Σz) / 3N` производится с использованием общей глобальной переменной, доступ к которой синхронизирован с помощью критической секции на основе мьютекса (`std::mutex`).

---

## Структура папки
* `6decomp.cpp` — исходный код параллельной программы с критическими секциями.
* `points.txt` — текстовый файл с входными координатами точек.

---

## Сборка проекта (Компиляция)

Сборка осуществляется через консоль разработчика (Developer Command Prompt для Visual Studio) или стандартный компилятор `cl` в режиме оптимизации `Release` (`/O2`):

```bash
cl /EHsc /O2 6decomp.cpp /fe:6decomp.exe
```

---

## Запуск программы

Имя входного файла жестко зафиксировано в коде программы (`points.txt`), поэтому передача параметров через аргументы командной строки не требуется. 

Для успешного выполнения программы входной текстовый файл должен находиться в одной директории с исполняемым файлом.

```bash
# Запуск программы
6decomp.exe
```

# Лабораторная работа №2: Параллельное умножение матриц

Папка содержит решение Задачи 4.

## Инструкция по сборке (через GCC)
```bash
g++ -fopenmp task4.cpp -o task4
```

## Инструкция по запуску
Программа принимает количество потоков и размер квадратной матрицы N.

Примеры запуска для 2, 4 и 8 потоков на матрице 1000x1000:
```bash
./task4 2 1000
./task4 4 1000
./task4 8 1000
```

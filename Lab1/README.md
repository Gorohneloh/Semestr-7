# Лабораторная работа №1: Основы OpenMP

Папка содержит решения Задач 1, 2 и 3.

## Инструкция по сборке (через GCC)
```bash
g++ -fopenmp task1.cpp -o task1
g++ -fopenmp task2.cpp -o task2
g++ -fopenmp task3.cpp -o task3
```

## Инструкция по запуску

### Задача 1: Приветствие из потоков
Запуск программы с указанием количества потоков:
```bash
./task1 8
```

### Задача 2: Вычисление среднего в массиве
Запуск программы с указанием количества потоков, размера массива и типа распределения (`static`, `dynamic`, `guided`):
```bash
./task2 8 16000 static
./task2 8 16000 dynamic
./task2 8 16000 guided
```

### Задача 3: Печать идентификаторов в обратном порядке
Запуск программы с указанием количества потоков и номера метода (от 1 до 5):
```bash
./task3 8 1
./task3 8 2
./task3 8 3
./task3 8 4
./task3 8 5
```

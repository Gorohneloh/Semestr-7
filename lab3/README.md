# Лабораторная работа №3. Многопоточные вычисления на C++

Решение Задачи №5 (вычисление геометрического центра множества 3D-точек) в рамках дисциплины «Аппаратные средства телекоммуникационных систем».

В данной работе реализованы две версии программы с использованием стандартных потоков C++ (`std::thread`):
1. **Loop Parallelization (5loop)** — распараллеливание основного цикла обработки данных по блокам.
2. **Functional Decomposition (5decomp)** — функциональная декомпозиция задачи на три независимых потока (по одному на каждую координатную ось X, Y, Z).

---

## Структура папки
* `5loop.cpp` — исходный код версии с распараллеливанием цикла.
* `5decomp.cpp` — исходный код версии с функциональной декомпозицией.
* `points.txt` — текстовый файл с входными координатами точек.

---

## Сборка проекта (Компиляция)

Сборка осуществляется через консоль разработчика (Developer Command Prompt для Visual Studio) или стандартный компилятор `cl` в режиме оптимизации `Release` (`/O2`):

```bash
# Компиляция версии с распараллеливанием цикла
cl /EHsc /O2 5loop.cpp /fe:5loop.exe

# Компиляция версии с функциональной декомпозицией
cl /EHsc /O2 5decomp.cpp /fe:5decomp.exe
```

---

## Запуск программы и аргументы командной строки

В соответствии с требованиями, параметры передаются строго через аргументы командной строки (`argv`).

### 1. Версия с распараллеливанием цикла
Принимает два обязательных аргумента: `<количество_потоков>` и `<имя_файла_данных>`.

```bash
# Запуск на 4 потоках с файлом points.txt
5loop.exe 4 points.txt
```

### 2. Версия с функциональной декомпозицией
Принимает один обязательный аргумент: `<имя_файла_данных>` (количество потоков жестко зафиксировано логикой алгоритма — 3 потока).

```bash
# Запуск с файлом points.txt
5decomp.exe points.txt
```
